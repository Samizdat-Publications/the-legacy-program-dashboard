## Decisions the builders made that a next session should know

- **Denial direction** comes from the adjudicated `denier` field on each edge, not from
  `a`; `notes/DENIAL-ADJUDICATION-2026-08-26.md` records that `a` is wrong on 27 percent of
  directed cases.
- **Band and era** are read from `data/l0-layout-model.json` (`current`), where
  `build_l0_layout.mjs` bakes them; the exporter fails loudly if the era table drifts.
- **Shorts** come from `data/l0-shorts.json` where authored, else the L0 model's derived
  short for map nodes, else the label. Class colours are the map's chip markers
  (`L0_CLS` in `tools/l0_patches.py`), not the old network map's palette.
- **Label mode** on the map has a second condition Design does not state: every label
  must also fit its column at 11 px. At 1366 both conditions fail, so cell mode holds
  either way; a check that re-derives the mode from height alone will disagree at some
  width in between.
- **No zoom on the map.** The layout is computed at 1:1 for the viewport; FIT recomputes,
  CELLS opts into cell mode. Zooming in had nothing to add once every name is drawn.
- **Neighbourhood ring slots** are a single 15 px lattice per side shared by every hop,
  stricter than Design's capture, and it is what makes "no two labels share a slot"
  literally true. Hop 2 is 136 nodes, not Design's 24, because Design's extract carried
  only map nodes.
- **Timeline** strand ids are the board's (`program`, `witness`, `oversight`, `coverup`);
  opening a year is component state, not URL, because section 2.1 defines only `?era=`
  and `?scope=`.
- **Patents** prosecution is a vertical list, not Design's horizontal track: eleven steps
  clipped at 1920, and a clipped label is the one thing the board must not draw. The
  eleventh sheet (US 2017/0313446) sits under an "Unmatched sheet" heading rather than
  being guessed onto a filing. Inventor and assignee are not printed as fields because no
  structured field carries them.
- **Evidence** rows render in blocks of 60 with an intersection observer; no page
  parameter, so every link stays a route.
- **The back button** is Stewart's condition on the new shell: one control in the bar on
  every route, including not-found, that steps backwards through the pages visited while
  researching. It calls `history.back()` and nothing else, so it creates no entry, the
  browser's own back does exactly the same thing, and forward still works. Whether there
  is an in-app page to return to is the one thing the browser will not report, so
  `app/src/history.ts` stamps each entry with its own depth in `history.state.tpDepth`
  using `replaceState`: no depth means a fresh push, a depth already there means the
  reader used back or forward. Depth 0 disables the control, which is what a cold deep
  link gets, so it can never take the reader off the site. A per-depth trail of
  `{ hash, title }` in `sessionStorage` feeds the tooltip alone. **C17** is eleven
  assertions over that: the control on all 37 screens the run walks, disabled on a cold
  deep link, a trail built by clicking Home's own start-here chip and then the node
  page's map link, two clicks stepping back over it in order, parity with Playwright's
  `goBack` and `goForward`, a forward stack that survives the clicks, and a tooltip that
  names the page it will return to. Its poison rewires the rendered button to set
  `location.hash` instead, and five of the eleven fail on it.

## The deploy recipe, and the one mistake to never repeat

Deploy the app from a clean export of `master`, never from the working tree and never
from the repo's `dist/`:

```
cd "C:\Users\stewa\OneDrive\Documents\Claude\Projects\Missing individuals connected to defense contractors\the-program"
python tools\build_app_data.py --check
```

then, in Git Bash (the path must be short: Windows refuses the scratchpad path for a
worktree):

```
rm -rf /c/w/next && mkdir -p /c/w/next && git archive master app | tar -x -C /c/w/next
cd /c/w/next/app && npm ci && npm run build && test ! -d dist/transcripts
npx wrangler pages deploy dist --project-name the-program-next --branch master --commit-dirty=true
```

On 2 September a first attempt chained `cd` into a worktree that had failed to create,
so `npx wrangler pages deploy dist` ran from the repo root and uploaded the OLD `dist/`,
which holds the transcript exports, to the review project for about a minute. The project
was deleted outright, recreated, and the transcript path confirmed to serve only the
app's page. The `test ! -d dist/transcripts` guard above is the lesson; a deploy script
should carry it.
