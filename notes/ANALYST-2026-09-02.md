# The analyst, made to work -- 2 September 2026

**What was true before this note.** No reader of the live board had ever received a
model-backed answer, and neither had anyone with a personal API key. Two faults in
series, neither visible to the gate:

| fault | effect | found by |
|---|---|---|
| Pages does not route `/api/*` to the Worker on a `pages.dev` host, and answers the health probe with the board's own HTML, status 200 | the endpoint never registered as live; every reader got the scripted branches | `curl` of the live health URL returning 16 MB of HTML |
| `SYSTEM_PROMPT()` threw: the inherited `caseContext()` read the parent board's fields and called `.join` on `unverified`, which is a string on some of this board's nodes | with a key, or once the endpoint was live, the turn sat on "thinking" for ever; the exception escaped before the `try` | typing a question in a Playwright browser and listening for `pageerror` |

The fifteen analyst assertions in the gate all exercised the scripted path. A check
that never sends a request cannot see a request that never sends.

**What is true now.**

| | |
|---|---|
| discovery | the client tries the same origin first, then the Worker's own hostname; the Worker's CORS allows the board's origin |
| the case file | rebuilt in `tools/analyst_patches.py`. A CASE INDEX of all 980 nodes, one line each, sent as a cached system block; a FOCUS block with the selected node in full (claims with tiers and sources, its hand-written edges, its dossier, open questions, FOIA requests) and its neighbours in brief, sent uncached |
| measured | index 166,547 chars, state 25,000 to 45,000 chars depending on selection, built in 4 ms. First turn: 77,327 tokens written to cache, 17,887 uncached. Later turns within five minutes read the 77k from cache at a tenth of the price |
| a real answer | "what is KONA BLUE and what is the strongest document behind it" answered in 11 seconds with ids cited, and moved the board to the NETWORK view on its own |
| failure modes | a timeout at three minutes, a message for an endpoint error, for an empty reply, for a length-limited reply and for a refusal; the question is no longer sent twice |
| the worker | accepts the system prompt as text blocks with `cache_control`, caps the total at 300k chars, per-IP limit 20 a minute, global limit 60 a minute, `max_tokens` 16000, passes `usage` back so the cache can be seen working in the network tab |
| the gate | five runtime assertions build the prompt on the real page and check its shape; `POISON=analyst` breaks the index reader on the real page and the check fails as it must |
| the chips | seven, for a first-time reader: start here, the AAWSAP lineage, Nimitz, custody, denials, money, the hostile audit. Two new scripted branches (`lineage`, `nimitz`) compute their figures from the nodes at answer time; twenty branch assertions |

**Cost note.** Opus 5 at high effort. A conversation's first turn costs about
fifty cents in input tokens; each later turn in the same five minutes about
thirteen cents plus output. The global limiter caps the worst case at sixty turns
a minute across every reader. If that is too much, the levers in order: a 1-hour
cache TTL on the index block (costs more per write, less per read), a smaller FOCUS
cap, `effort: "medium"`.

**What is still owed.** The 5-minute cache means a reader who thinks for six
minutes between questions pays the write again. The scripted footer still says
"no API key is set" when the reason is the endpoint being down; a wording pass
would help. The seven chips could carry one-line teasers under them; the analyst
console has the room now that the opening wall is gone.
