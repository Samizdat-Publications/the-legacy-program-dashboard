## 4. The five things a next session must not undo

1. **`tools/test_packed_layout.js` drives the PROGRAM tab.** It was navigated, not weakened —
   one line changed, all 31 assertions and every poison intact. If it goes red, fix the map.
2. **The particle rule now governs the default surface.** A particle draws only on the
   selected node's edges, running away from the reader, never along the time axis. That was
   Design's ruling on a fallback the inversion has promoted to the first thing every reader
   sees. `e.pair.flip` must never steer a particle again.
3. **`paint()`'s camera step names BOTH map views.** It said `S.view === 'NETWORK'`, which was
   right while the packed map *was* that view's rest state. Narrow it again and the program
   map's breadcrumb, ledgers and register panel freeze while the canvas keeps drawing, with
   nothing thrown.
4. **`capture_strip.js` navigates to PROGRAM and exits non-zero without the crumb.** It used
   to capture on boot, which worked only because the packed map was the rest state. Left
   alone it would have dropped the crumb and made `audit_independent` skip
   `breadcrumb object count` **in silence** — the failure that file's own comment warns about.
5. **The patents and FOIA content lives in data, not in a renderer.** Both are gate-checked:
   every quotation against the transcript it cites, every request against a question that is
   actually open. A string typed into `patents_patches.py` is a string nothing checks.

## 5. Three parsers and renderers that reported success while not doing the job

All three are the `CLAUDE.md` §5 shape and all three were caught by reading output against
source rather than by trusting a summary line. Worth reading before writing the next one.

- **`build_foia_links.py` dropped four claims and reported a clean parse.** It matched an id
  followed by a run of Q-numbers and stopped at the first word it did not expect, so
  `partially Q3`, `materially advances Q6 and Q11` and `partially Q1` were read, discarded,
  and counted out of the total. **117 was wrong and looked right.** It now counts every
  `Q\d+` in the line against the number attributed and raises on a mismatch. 121.
- **The patents CSS shipped a Python octal escape.** `quotes:'\201C' '\201D'` is correct CSS;
  the module carrying it used a **non-raw** Python string, so `\201` became U+0081 and the
  `C` survived as a literal. Every quotation printed a box and a capital letter. The CSS was
  right and the file that emitted it was not.
- **The mockup's own header was wrong and would have shipped verbatim.** `5 FILINGS ·
  2 GRANTED`; three are granted. The strip is derived from the arrays now.
