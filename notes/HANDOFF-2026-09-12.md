## 4. Things a next session must not undo

- **The analyst's tools run in the browser, not the Worker.** That is why a
  public endpoint is not a liability: the Worker holds no copy of the board.
- **Thinking blocks are relayed untouched** and **all tool results go back in ONE
  user message**. The first is because the signature covers the text; the second
  because splitting them teaches the model to stop calling tools in parallel.
- **One cache breakpoint in the messages, and it moves.** `moveBreakpoint()`
  clears the last one before setting the new one. Adding without clearing is a
  400 on the fifth round, and it is invisible to the reader.
- **Nothing may take height from `.map-root` or `.hood`.** The map has about 7px
  of clearance at 1920 on CI, where the fallback font wraps two more rows than
  Windows does. A 30px dock reservation put its lowest chip 23px into its own
  legend and CI caught it. The analyst's closed tab overlays the band-label
  gutter instead, and C18 asserts it covers nothing on a page that cannot scroll.
- **`TOOLS_VERSION` is in two files** and a change to either is a deploy to both.
- **Tier strictly dominates the search ranking.** Position and the node bonus are
  bounded at 0.5 and 0.25 so neither can outweigh one tier. That is not tuning:
  a ranking where an early mention pushes a documented claim below an inferred
  one argues the opposite of what this board is.
- **A thread report may cite only the authored thread file or an edge source the
  board carries.** C21 exists for exactly that and its poison is a plausible
  archival citation.
- Everything in the 4 September handoff's section 4, all still true.
