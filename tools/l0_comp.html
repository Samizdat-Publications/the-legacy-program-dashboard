Packed-Cell Layout Comp

Design's layout, rendered from data/l0-layout-model.json exactly as generated. The question this answers, and the only one: does position now mean something? Columns are eras left to right. Rows are bands, ordered by measured mean custody proximity, descending. Every chip is the same size — size is deliberately not a channel.

This is a comp, not the map. The live board is untouched. It draws to a canvas and still uses the force layout. Nothing here has been seen on a real screen by anyone — it was generated headless, so judge the arrangement, not the pixel polish.
